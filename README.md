# Mukesh Gupta — LIC Advisor Website

A complete responsive advisory website for Mukesh Gupta / Gupta Enterprises, redesigned in a custom LIC-inspired editorial system.

## Included

- LIC hands-emblem branding and independent-agent disclosure
- Protection, savings, child-future, retirement, money-back and health-related planning content
- Policy servicing, status guidance and forms/document checklists
- Browser-only indicative premium calculator
- Expandable FAQ, responsive navigation and WhatsApp enquiry flow
- Privacy and terms summaries
- Desktop, tablet, mobile and reduced-motion support

## Run locally

Requirements: Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```

## Main files

- `app/page.tsx` — content, interactions and contact details
- `app/globals.css` — complete visual system and responsive layout
- `app/layout.tsx` — page title, description and favicon
- `public/assets/` — LIC logo and supplied editorial images

The calculator is an educational budgeting illustration, not an LIC quotation. The WhatsApp form does not store submissions on the website.
